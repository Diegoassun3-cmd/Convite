# Pasta de mídia

Coloque aqui os arquivos que você referenciar em `config.js`:

- `foto-capa.jpg` — foto de capa exibida dentro do convite (quando `midia.tipo = "foto"`).
- `video-capa.mp4` — vídeo de capa (quando `midia.tipo = "video"`). Prefira um vídeo curto (5–15s),
  sem áudio ou com áudio dispensável, e leve (poucos MB) para carregar rápido no celular.
- `video-poster.jpg` — imagem exibida enquanto o vídeo carrega.
- `foto-1.jpg`, `foto-2.jpg`, ... — fotos extras da mini galeria opcional.

Você também pode apontar `fotoUrl` / `videoUrl` em `config.js` para uma URL externa
(ex: um link direto de imagem/vídeo hospedado no Cloudinary, Imgur, etc.) em vez de
subir o arquivo aqui — nesse caso esta pasta pode ficar vazia.
